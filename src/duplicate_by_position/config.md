## Duplicate & Reorder by Position

- `shortcut_duplicate` — duplicate the selected note(s) right after the original *(default `Alt+D`)*.
- `shortcut_move_up` / `shortcut_move_down` — move the selected new cards one position up / down among the cards shown in the browser *(default `Alt+Up` / `Alt+Down`)*.
- `tag_for_copies` — tag added to every copy, e.g. `"duplicate"`. Empty = no tag.
- `select_copy` — select the new copy in the browser after duplicating.

Leave a shortcut empty (`""`) to disable it. Restart Anki after changing shortcuts.

---

- `shortcut_duplicate` — дублировать выделенные заметки сразу после оригинала *(по умолчанию `Alt+D`)*.
- `shortcut_move_up` / `shortcut_move_down` — сдвинуть выделенные новые карточки на позицию вверх / вниз среди показанных в браузере *(по умолчанию `Alt+Up` / `Alt+Down`)*.
- `tag_for_copies` — метка для каждой копии, например `"duplicate"`. Пусто — без метки.
- `select_copy` — выделять созданную копию в браузере.

Пустая строка (`""`) отключает сочетание. После смены клавиш перезапустите Anki.
